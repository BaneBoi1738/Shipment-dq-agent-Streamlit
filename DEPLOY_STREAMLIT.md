# Deploy in 10 minutes (free)

1. Put the project on GitHub (repo root must contain app.py, requirements.txt, src/, data/).
   In VS Code terminal:
   git add . && git commit -m "Add Streamlit demo app" && git push
2. Go to share.streamlit.io, sign in with GitHub.
3. New app -> pick your repo, branch main, main file path: app.py -> Deploy.
4. Wait ~2-3 min. You get a link like https://<name>.streamlit.app
5. Test it yourself with the 5 Day 12 files before posting.
